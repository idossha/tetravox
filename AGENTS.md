# Working on Tetravox (for humans and agents)

Read `docs/ARCHITECTURE.md` first — it is the contract. `docs/ROADMAP.md` says what is in flight.

## Commands
- `pnpm install` · `pnpm wasm` (builds crates/tvx-wasm → packages/wasm/pkg) · `pnpm build` · `pnpm test` (cargo test + vitest) · `pnpm e2e` (Playwright) · `pnpm dev` (Electron dev) · `pnpm package`
- Rust only: `cargo test --workspace`, `cargo clippy --workspace -- -D warnings`, `cargo bench -p <crate>`

## Rules
1. Rendering work is verified by **screenshots** (Playwright), never by "it compiles". Look at the PNG.
2. Every parser/geometry function ships with synthetic tests + a real-data test gated by `TETRAVOX_TESTDATA`.
3. Disjoint ownership: one agent per crate/package. Shared files (`Cargo.toml` workspace, root `package.json`) are pre-populated by the scaffold; only append.
4. Conventional commits, **no `Co-Authored-By` trailers**. Commit on your own branch in your own git worktree (`git worktree add ../tetravox-wt-<name> -b feat/<name>`); never rewrite `main`.
5. No new dependency without a line in `docs/DECISIONS.md`.
6. Never block the UI thread with parsing or geometry; all of it goes through the compute worker.
